# Data/app_init/roads

Read-only road master area for app initialization.

Files:

- `road_network.geojson`
- `priority_roads_level0.geojson`
- `priority_roads_level1.geojson`
- `priority_roads_level2.geojson`
- `priority_roads_level3.geojson`
- `manual_add_candidate_roads.geojson`

`road_network.geojson` is the connection road network used by D3 and
recalculation. It is copied from `Data/interim/C1_roads.geojson`, generated
for `Naie, Sorachi, Hokkaido, Japan` with `network_type=drive`, and contains
1767 rows.

These files are generated by a separate process or app, not by D3_app.py.
Do not move or delete existing `Data/interim/C5_priority_roads_level*.geojson`
as part of this layout commit.

`manual_add_candidate_roads.geojson` contains roads that are not initial
targets for any `road_selection_level`, but can receive manual diff
instructions in D3. The current population is pure `unclassified` roads from
`road_network.geojson`, excluding roads already present in
`priority_roads_level3.geojson`.
