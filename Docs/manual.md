# 奈井江町除雪計画支援アプリ 操作手順書

## 1. 事前準備（モードの選択と除雪レベルの決定）
本アプリには、動作の検証や計画の検討を行う **「デモモード」** と、当日の気象データを用いる **「実運用モード」** の2つがあります。

- **A. デモモードの場合**（過去データを使ったシミュレーションや手動計画）
  1. 画面上の **「デモモード」** を **オン** にします。
  2. 除雪レベルの決定方法を以下から選択します：
     - **「推論日を使用する」を選択した場合**：推論対象の「日付」と「時刻」を指定して「気象レベルを推定」ボタンを押すことで、過去の気象データからレベルを自動推定させます。
     - **「レベルを指定する」を選択した場合**：「除雪レベルの設定」セレクトボックスから、Level 0 〜 3 のいずれかを手動で指定します。
  3. 決定したレベルに基づいて、計画の対象となる道路網（グレーの線）が地図上にロードされます。

- **B. 実運用モードの場合**（当日の実運用）
  1. **「デモモード」** を **オフ** にします。
  2. 自動的に気象庁APIから最新の気象データが取得され、現在の降雪状況に応じた適切な除雪レベル（Level 0 〜 3）がシステムによって自動推定されます。
  3. 推定されたレベルに基づき、本日の除雪計画の対象となる道路網が地図上にロードされます。

---

## 2. 地図上でのスタート地点（出発点）の設定手順
出発点は、キーボードのキーを併用して地図上をクリックすることで設定します。（※ここでの設定は、最後に「再計算」ボタンを押した時点で計画に反映されます）

- **`Ctrl + 左クリック`**
  - クリックした位置を新しい出発点（緑色のピン）に設定します。
- **`Ctrl + Shift + 左クリック`**
  - 出発点を、最後に再計算が正常完了（確定）した時点の元の出発点に戻します。

---

## 3. 道路 of クリック操作（計画条件の個別調整）
地図上で道路をクリックすることで、除雪レベルによる自動選定とは別に、個別に計画の条件を調整できます。

- **`左クリック`（通常クリック）**
  - クリックするたびに、道路の設定状態が以下の順序で循環して切り替わります：
    - **`黒`（除外）** → **`元の色`（通常候補）** → **`マゼンタ`（追加）** → **`オレンジ`（条件付き）** → **`黒`**
  - ※すでに計算結果で **`赤`（未達）** になっている道路をクリックした場合は、直接 **`マゼンタ`（追加）** の状態に戻すことができます。
- **`Shift + 左クリック`**
  - その道路の操作状態をすべて解除し、通常状態（再計算直後の表示状態）に戻します。

---

## 4. 地図上の色表示と意味一覧

地図上に表示される道路や計画されたルートの色は、それぞれ以下の意味を持っています。

### 道路の設定状態（計画時の条件指定）
- **`黒`**：**経路から除外する道路**。再計算の際、この道路を走行ルートから除外（通行禁止）します。
- **`マゼンタ / ピンク`**：**除雪のターゲットに含める（強制追加する）道路**。レベルを問わず、強制的に除雪計画の対象に含めます。
- **`オレンジ`**：**条件付きで経路に含めてもよい道路**。なるべく使用したくないが、経路計算上有利であれば経由や除雪の対象に含めても良いという状態です。
- **`グレー（濃いグレー）`**：**経路計画に含めることのできる道路（通常候補）**。指定した除雪レベルにおいて、除雪対象となっている標準的な道路です。
- **`薄いグレー`**：**経路計画の対象外の背景道路**（地図上では操作できません）。

### 除雪計画ルート（再計算の計算結果）
- **`青`（Target）**：**除雪走行区間**。実際に除雪を行いながら走行する計画ルートです。
- **`水色`（Connector）および`深い水色`（Return / 返路）**：**除雪ターゲットに到達するのに経由する道路**。除雪を行うかどうかは関係なく、次の除雪区間への移動や、基地へ戻るために経由・走行するルートです。
- **`赤（実線）`（unmetTarget）**：**未達道路（全未達）**。除雪対象に指定されていたが、ルートの接続性などの問題でカバー（除雪）できなかった区間です。
- **`赤（破線 / 点線）`（partialUnmetTarget）**：**部分未達道路**。片側のみなど、部分的にしかカバーできなかった除雪区間です。

---

## 5. 再計算の実行
1. 出発点の設定や道路の調整（追加・除外）が終わったら、**「再計算」** ボタンをクリックします。
2. これにより、指定した条件に基づいて最適な **除雪計画** が計算され、地図上に青・水色の計画ルートや赤い未達区間が描画されるほか、総走行距離や除雪網羅率（カバー率）が出力されます。
